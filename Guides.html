How to make a Button Activator (Wii)


Tools:
Dolphin Debug Mode
Dolphin Memory Engine (DME)


First, what you are going to want to do is start up the game you want to make this (This tutorial uses NTSC Wii Play v1.0) for and load Dolphin Memory Engine. When you load into it make sure you have these EXACT Settings.

Now press any button on a Real Wii Remote (or a keyboard with hotkeys), and pause Dolphin. Now go into the text box in DME and type in what you see here (Hexadecimal)


Controls:
A: 800
B: 400
1: 200
2: 100
MINUS: 1000
PLUS: 10
UP: 8
DOWN: 4
LEFT: 1
RIGHT: 2
Z: 2000
C: 4000


Now you will see results, let go of the button and type 0, you should see about 20-30 results.

Usually for me, the first address that ends with "A" works. It might be different for you but pick the first with the "A" at the end. Now right-click on the address and copy it. Go back to Dolphin, right click on your game, select "Properties", and go to the Gecko Codes Tab

Click "Add New Code...", give it a name, and put the address in the Code Text Box. Replace the 80 with 20 to make it a If Equal code. Subtract 2 (in Hex) from the address (0xA - 0x2 = 0x8). Add 0000XXXX (Replace X's with the Button you want). Add the Code you want the button to trigger when pressed, and add "E0000000 80008000". (Optional: Add CC000000 00000000 to make it be like a On/Off Gecko Codes) It should look like this.

If you did it right, you just made your own button activator!

How to make a Custom Charge Stage (Wii Play) [WORK IN PROGRESS]


Tools:
ROM of Wii Play you have LEGALLY
Dolphin
Brawlcrate
3D Model Software (Blender for this)
KCL, PMP, and KMP Editors (Provided here)


Go to Dolphin and find your path with your ROMS, right click on the Wii Play one and click "Properties", go to "Filesystem", and right-click on the one that says "Disc" and click "Extract Entire Partition". Make a new folder and put it in There

Get any 3D Model you want, I'll be using SNES Mario Circuit 1 from Mario Kart DS, open it in your 3D Modeling software (Blender for me) and if it's one object, go to "Edit Mode" and click P to seperate by Materials. Go back into Object Mode and size it to your liking
Once it's scaled to something big enough and you like, you can export the file as an .obj file into a new folder (DO NOT CLICK THE LEGACY ONE)

Next, we're going to work on the collision. Download the .zip file to get access to all the tools for this. You'll need ALL of them for later.

CustomWiiModelTools.zip

For now, open KCL Importer and Lorenzi's KMP Editor. On the KCL Importer, click "From Object" and select the .obj file you exported. Select Material by Meshes, Change the Game to Default and the Platform to Wii. Here are each collision type (THESE ARE JUST MY GUESSES):


0x1: Road
0x2: Grass
0x3: Fence


If anyone wants to correct me on this, let me know. Set these collision values for each object (Remember which is which). The KCL will then export (unless there's too much polygons) and save it. Open Lorenzi's KMP Editor and click "Import Model". Select the .kcl file and click the objects tab. Click Alt+Left-Click and check the Y Axis (THIS IS VERY IMPORTANT)
Go back into your 3D Modeling software and move to object down, if you're on Blender, a tab called "Move" will appear. Expand it and change the Z to -[Original Y Axis Value].
Export the .obj again and repeat the same steps from earlier. If you did it right, the Y axis should show 0 (with decimals).
Why do this? In Charge, the cow can NOT go up at all, even with PMP editing and working collision. The only exception to this is the cow jumping

Exit the 3D Modeling Software and then open it again (Sounds very stupid but just wait). Import the .obj file and rotate it -90 by it's X Axis (for some reason, BrawlCrate just rotates it 90 degrees when importing). Export as .dae and open BrawlCrate.
Open "Common/RPCowScene/common.carc" from the folder with your Wii Play Data into Brawlcrate. You'll need to focus on 3 files for this

1. cow_field1P.kcl
2. cow_field1P.pmp
3. G3D/cow_field.bress/3DModels(N4WR)/cow_field1P.mdl0
Replace the kcl with your modified one. Export the .pmp for later and right-click on the model and go to "Import Asset => Object" and import the .dae file. You'll get a confirmation screen, copy these settings and click okay.
Make sure to click "Merge both models" and click okay. Import the textures by going to the .bress file and click "Import => Textures". Select ALL of your textures and make sure you set every photo's format to "CMPR" (it will look low quality but it's better than crashes)
Go to the plus sign on the model and click the Objects folder and click the delete button on the original objects (DON'T DELETE THEM USING CTRL+DEL)
Go to the Shaders folder and go to the last shader. Expand it and click Stage0 and set the scale to "MultiplyBy2". If you have transparent texures, go to its material in the Materials Folder and set them to these EXACT settings.
Open the PMP Editor and open the pmp file in there. Open the Group 0x0007 and ignore all of the Objects EXCEPT "0x0001" and "0x0002". These are the start and goal. Open the kcl in the KMP Editor and add 2 objects. One is for the start and one is the Goal. Copy and paste the values from the KMP Editor into the PMP Editor and save in the PMP Editor (It will ask you to Save As, just rename it). Replace the original pmp file in BrawlCrate and then save the file.

In order to test it, go to Config in Dolphin, then Paths and add the folder with your Wii Play Stuff with the "sys" folder. Open it and if you did it right, it should work!
Hopefully this helps! I'll have better info in the future, but I wanted to share my knowledge to you.
